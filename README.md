# Cars Dealership Full-Stack Capstone Project

## Project Overview
The Cars Dealership application is a full-stack web application for a national car dealership retailer in the United States. It allows users to explore dealership branches, view dealer information, register and log in, and submit reviews.

## Key Features
- User registration, login, and logout
- Browse all dealerships
- Search dealerships by state
- View dealership details and customer reviews
- Submit dealership reviews
- Analyze review sentiment
- Responsive user interface
- Automated testing and deployment using CI/CD

## Technology Stack
- Frontend: React
- Backend: Django, Flask, and Node.js microservices
- Database: SQLite and MongoDB
- Containerization: Docker
- Orchestration: Kubernetes
- Deployment: IBM Cloud Code Engine
- Version Control: Git and GitHub
- CI/CD: GitHub Actions

## Project Structure
The project will contain frontend components, backend services, API endpoints, database configuration, and deployment workflows.

## Project Status
Under development as part of the Full-Stack Development Capstone.
